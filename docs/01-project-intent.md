# Project Intent

I am building this project to understand how steganography is used to
hide malicious or covert data inside files shared over platforms like WhatsApp.

My concern is towards the people getting there devices, accounts hacked by just downloading a image, video or any file on platforms like whatsapp. The reason behind that is steganography that's why i am making this software.

Currently this project will need user to upload the stego file and it will detect and repair the file if possible. But in future i will extend it by making a software for mobile apps which will automatically detect the incoming files(images, videos, docs) and scan it and notify the user before even the user opened it.

This project is for learning cybersecurity concepts such as:
- Steganography detection
- Statistical analysis of digital media
- Defensive security tools

This is my first cybersecurity project.
Accuracy is not the goal — understanding is.
